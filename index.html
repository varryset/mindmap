Colour tags

Give each colour a meaning, e.g. red = Urgent, blue = Priya. You can rename any time. Named colours show as chips at the bottom of the map with a count: tap one or several to filter, or drag a chip onto a node to tag it. Tap a tag on a node to remove it. A node can carry several colours; they are blended and each one shows as a small badge on the node.

Reading the lines
Solid line – main flow. The dot is where it starts, the arrow is where it ends.
Dashed line – an extra link: this node also feeds into the node at the arrow.
↺ Loop back – feeds back to an earlier node. It curves underneath the nodes.
Yellow pill – the process note on that line. Tap a line or pill to edit it.
Tap a node – its lines light up and little dots run from start to end. Everything else fades. Tap empty space to see all lines again.
